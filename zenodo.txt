ipa_verbatim: Automated Multi-Tier IPA Transcription and Syllabification for Turkish Speech Recordings

Description
-----------
<p>A Python command-line application that aligns speech audio files to
IPA (International Phonetic Alphabet) symbols using the
<code>facebook/wav2vec2-xlsr-53-espeak-cv-ft</code> model, and derives a
rule-based syllables tier from the resulting phoneme alignment.</p>

<p>For each input <code>.wav</code> file, the tool produces a phoneme
text file (IPA symbols), a multi-tier Praat TextGrid, and a
frame-level probability table. Audio files in other common formats
(M4A/AAC, MP3, OPUS, AMR, OGG, FLAC, DSS/DS2, WMA, 3GP/3GPP, CAF) are
automatically converted to 16 kHz / 16-bit / mono PCM WAV before
processing. Runs on Linux, macOS, and Windows, with optional GPU
acceleration (CUDA / Apple Silicon MPS).</p>

<p>Gelistirici not: Turkce konusma kayitlarindan otomatik, cok
katmanli IPA transkripsiyonu ve heceleme uretmek icin gelistirilmis
bir komut satiri araci.</p>
