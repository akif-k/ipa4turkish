This package runs as a Python application on Linux, macOS, and Windows.
The runtime is provided via a conda environment named "verbatim" (see
environment.yml); some dependencies such as espeak-ng and ffmpeg must be
installed separately. Model files are shipped locally inside this
package, under models/ (or downloaded automatically on first run).
